🚀 Programmatic Client SDK Integration

Wrap your AI agent tool calls through the out-of-process AgentWall proxy using thin client SDKs:

Python SDK (agentwall) pip install agentwall 
from agentwall import AgentWallClient

client = AgentWallClient()

@client.governed
def my_tool(param: str):
    return run_logic(param)
TypeScript SDK (@vexa/agentwall) npm i @vexa/agentwall 
import { AgentWallClient } from "@vexa/agentwall";

const client = new AgentWallClient();
const tool = client.governed("name", async (args) => {
  return await execute(args);
});
